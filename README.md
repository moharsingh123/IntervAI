# 🚀 IntervAI – AI Powered Interview Preparation Platform

IntervAI is a full-stack AI-based interview preparation platform that helps users practice real-world interview scenarios with intelligent feedback and performance analytics.

It is designed to simulate technical and HR interviews, analyze resumes, and improve candidates’ confidence and communication skills.

---

## 🌟 Features

* 🤖 AI-generated interview questions (Technical & HR)
* 📄 Resume analysis (extract skills, projects, experience)
* 🎤 Voice-based interview simulation
* 📊 Performance analytics & feedback
* 💳 Payment integration (Razorpay)
* 🔐 Secure authentication system
* 🌐 Fully responsive modern UI

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/IntervAI.git
cd IntervAI
```

---

### 2. Install dependencies

#### For backend:

```bash
cd server
npm install
```

#### For frontend:

```bash
cd client
npm install
```

---

### 3. Setup environment variables

Create a `.env` file in the **server** folder:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
RAZORPAY_KEY_ID=your_key
RAZORPAY_SECRET=your_secret
```

---

### 4. Run the project

#### Start backend:

```bash
cd server
npm run dev
```

#### Start frontend:

```bash
cd client
npm start
```
